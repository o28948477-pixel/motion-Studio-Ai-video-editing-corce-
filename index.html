GUIDEStep-by-step Guide

PDF-er shob step ek jaygay. UI-er button/menu update hole position ba label change hote pare.

Kon workflow choose korbe?
  • Motion graphics heavy: Remotion + Claude Code
  • Cinematic footage heavy: Runway / Pika
  • Hybrid workflow: duita mila-ye (recommended)

Age storyboard banao, tarpor production shuru koro. Recommended setup: Remotion = motion graphics engine; Claude Code = coding assistant; Runway/Pika = generated footage; CapCut/Premiere Pro = final edit and audio. Flow: Preview > Render > Quality check > Publish.

Claude Code open kora
  1. Claude Desktop open koro
  2. Code tab choose koro
  3. Project folder select koro
  4. New session start koro
  5. Prompt likho

Terminal diye korle official setup instruction follow koro (Commands section dekho). Claude Code-ke project folder-er bhitore theke start koro, jate se oi project-er file read/edit korte pare.

Remotion project setup
  1. Project folder create koro
  2. Terminal open koro
  3. Setup command run koro
  4. npm run dev chalao
  5. Browser preview check koro

Command-er kaj: prothom line project create kore; cd project folder-e jay; remotion skills add coding agent-er jonno Remotion guidance add kore; npm run dev local preview server start kore.

Remotion Studio: preview ebong check
  1. Preview / Player open koro
  2. Composition choose koro
  3. Frame ebong timing check koro
  4. Project file edit koro
  5. Final video render koro

Browser preview-te video play kore typography, timing, safe margin, transition, image crop ebong spelling check koro. Final render-er age full preview ekbar dekhe nao.

Runway / Pika: text-to-video

Runway/Pika open koro, Text-to-Video choose koro, ekta scene prompt paste koro, available settings-e 9:16 select koro, Generate, tarpor clip review kore save koro. Ei tools Remotion-er replacement noy; choto cinematic clip Remotion ba CapCut timeline-e use korbe.

Runway / Pika: image-to-video
  1. Video creation tool open koro
  2. Reference image upload koro
  3. Motion prompt likho
  4. Available settings choose koro
  5. Generate kore review koro
Voiceover, music ebong sound effect
  • Age script final koro, tarpor voiceover record/generate koro.
  • Voiceover-er pause mark kore scene duration set koro.
  • Music narration-er niche low volume-e rakho; important dialogue clear thakte hobe.
  • Sound effect transition, title reveal ebong impact moment-e; every cut-e noy.
CapCut / Premiere Pro final editing

CapCut-e New Project, rendered clips import, timeline-e scene order set, voiceover add, subtitle add, music/SFX add, logo/CTA add, export.

  • Voiceover-ke timeline-er main track rakho; visual clip tar sathe sync koro.
  • Subtitle readable rakho: short line, clear contrast, safe margin.
  • Colour grading-e shob clip-er look consistent rakho.
  • Logo, CTA, music fade-out ebong final frame check koro.

01Kon tool ki kaj kore

Duita alada category: precise text/chart/UI animation-er jonno Remotion, cinematic clip-er jonno Runway/Pika. Duita mila-le hybrid workflow.

Claude Code

Project-er code create, edit, debug kore. Nijey video editor noy; Remotion-er moddhe animation code likhe.

Remotion

React-based video framework. Text animation, chart, timeline, logo reveal ebong exact timing-er jonno best.

Runway / Pika

Text-to-video ba image-to-video diye cinematic footage. Egulo Remotion-er replacement noy.

CapCut / Premiere

Clip, Remotion render, voiceover, music, subtitle ebong final export ek jaygay combine.

Phone-only hole: Remotion setup practical noy. Runway/Pika browser tool + CapCut mobile diye start koro.

Claude-ke ki information dibe?

  • Topic: video kon bishoy niye
  • Goal: viewer ki feel ba learn korbe
  • Audience: kar jonno (age, bhasha)
  • Duration: 30, 60 na 90 sec
  • Platform: Facebook Reels, TikTok, YouTube Shorts
  • Visual style: dark cinematic, documentary, funny, fantasy
  • Output: script, storyboard, scene prompt, motion graphics, editing plan

0290-second video planning

Ekbare generate korbe na. 12-15 ta scene-e vag koro, protita scene age theke likhe nao.

Voiceover final korar por scene timing set koro. Pause ebong dramatic delivery-r jonno jayga rekho.

04Terminal Commands

Computer-er jonno (Windows PowerShell, macOS Terminal, Linux). Claude chat-e command likhle seta nijer theke run hoy na.

Kothay ki

Install/project command = Terminal. Natural-language instruction = Claude Code session. Preview = browser. Render command = Terminal.

AI clip quality check

  • Face, hands, clothing, background consistency dekho.
  • Flicker, unwanted object, text artifact thakle regenerate koro.
  • Same character hole same reference image + description use koro.
  • 90s video-r jonno 4-6 ta strong clip-o enough; baki scene Remotion typography diye.

Common problems

  • Claude wrong code likhle exact error paste kore specific fix chao.
  • Preview blank hole terminal error, composition registration, project setup check koro.
  • Render slow hole short test render diye assets/dependencies check koro.
  • Sound: music narration-er niche low volume-e; SFX shudhu transition/title/impact-e, every cut-e noy.

06Rules ebong Export Checklist

Tick koro; progress dekhabe (page reload korle reset hobe).

Important rules

  • Ekbare 15 scene build koro na; ekta build kore approve koro.
  • Claude-ke password, API key ba private credential dio na.
  • Terminal command run korar age tar kaj bujhe nao.
  • Claude Code file delete/overwrite korte chaile review koro.
  • Music, font, footage ebong image-er license check koro.
